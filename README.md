# TypeScript Image Gallery Demo

A small demo gallery built with React + Vite + TypeScript.

Features:
- Responsive grid
- Lazy-loading thumbnails
- Accessible lightbox with keyboard navigation
- Preloads adjacent images

Run:
1. npm install
2. npm run dev
3. Open the provided URL (usually http://localhost:5173)

Replace the images in `src/App.tsx` with your own URLs or load them dynamically from an API.
